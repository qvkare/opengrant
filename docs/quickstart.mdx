## Using the SDK

Install the SDK in your Node.js/TypeScript project:

```bash
npm install @opengrant/sdk
```

### Basic Usage

```typescript
import { OpenGrant } from '@opengrant/sdk';

const client = new OpenGrant({
  apiKey: 'og_live_xxx',
  privateKey: '0x...', // For automatic USDC payments
});

// Make a paid API call
const response = await client.post('tailwind', '/v1/generate', {
  input: 'A blue primary button with rounded corners',
});

console.log(response.data);
// { classes: 'bg-blue-500 text-white px-4 py-2 rounded-lg' }
```

The SDK handles the x402 payment flow automatically:
1. Sends your request to the API
2. If a 402 Payment Required is returned, signs an EIP-3009 USDC transfer
3. Submits the payment to the facilitator
4. Retries the request with the payment token

### Multi-Chain

By default, the SDK uses Base (chain ID 8453). To use a different chain:

```typescript
const client = new OpenGrant({
  apiKey: 'og_live_xxx',
  privateKey: '0x...',
  chainId: 42161, // Arbitrum
});
```

See [Multi-Chain Support](/sdk/multi-chain) for all supported chains.

## Using the CLI

Install the CLI globally:

```bash
npm install -g @opengrant/cli
```

### Authentication

```bash
# Interactive login (opens browser)
opengrant login

# Headless login (private key)
opengrant login --headless

# Check who you're logged in as
opengrant whoami
```

### Managing API Keys

```bash
# Create a new API key
opengrant keys create --name "my-app"

# List all keys
opengrant keys list

# Revoke a key
opengrant keys revoke <keyId>
```

### Wallet Operations

```bash
# Check balance
opengrant balance

# Fund your wallet
opengrant fund 50
```

### Publisher Commands

```bash
# Verify GitHub identity
opengrant publish verify-github --token ghp_xxx

# Register a new API
opengrant publish create-api \
  --name "Weather API" \
  --slug "weather" \
  --url "https://api.weather.example.com" \
  --github-repo "user/weather-api" \
  --github-token ghp_xxx

# Activate the API
opengrant publish activate weather
```

## Local Development

To run the full OpenGrant platform locally:

### Prerequisites

- Node.js 20+
- pnpm 9+
- Docker (for PostgreSQL and Redis)
- Foundry (for smart contract development)

### Setup

```bash
git clone https://github.com/qvkare/opengrant.git
cd opengrant

# Install dependencies
pnpm install

# Copy environment variables
cp .env.example .env

# Start infrastructure (PostgreSQL, Redis)
pnpm docker:dev

# Run database migrations
pnpm db:push

# Start all development servers
pnpm dev
```

This starts:
- **API server** at `http://localhost:3001`
- **Web app** at `http://localhost:3000`

### Running Tests

```bash
# All JS/TS tests (281 tests)
pnpm turbo test

# Solidity tests (232 tests)
cd packages/contracts && forge test -vvv
```
