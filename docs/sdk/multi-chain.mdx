## Supported Chains

## Configuration

Specify `chainId` when creating the client:

```typescript
import { OpenGrant } from '@opengrant/sdk';

// Base (default)
const baseClient = new OpenGrant({
  apiKey: 'og_live_xxx',
  privateKey: '0x...',
  // chainId: 8453 (default)
});

// Arbitrum
const arbClient = new OpenGrant({
  apiKey: 'og_live_xxx',
  privateKey: '0x...',
  chainId: 42161,
});

// Base Sepolia (testnet)
const testClient = new OpenGrant({
  apiKey: 'og_test_xxx',
  privateKey: '0x...',
  chainId: 84532,
});
```

### Custom RPC URL

Each chain has a default public RPC URL. Override it for better performance:

```typescript
const client = new OpenGrant({
  apiKey: 'og_live_xxx',
  privateKey: '0x...',
  chainId: 8453,
  rpcUrl: 'https://base-mainnet.g.alchemy.com/v2/YOUR_KEY',
});
```

## Chain Utilities

The SDK provides utility functions for working with chains:

### getChainConfig

Get the full configuration for a chain:

```typescript
import { getChainConfig } from '@opengrant/sdk';

const config = getChainConfig(8453);
// {
//   chainId: 8453,
//   name: "Base",
//   network: "eip155:8453",
//   usdc: "0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913",
//   rpcUrl: "https://mainnet.base.org",
//   testnet: false,
// }
```

### getUSDCAddress

Get the USDC contract address for a chain:

```typescript
import { getUSDCAddress } from '@opengrant/sdk';

const usdc = getUSDCAddress(42161);
// "0xaf88d065e77c8cC2239327C5EDb3A432268e5831"
```

### getNetworkId

Get the CAIP-2 network identifier (used in x402 protocol):

```typescript
import { getNetworkId } from '@opengrant/sdk';

const network = getNetworkId(8453);
// "eip155:8453"
```

### SUPPORTED_CHAINS

Access the full chain configuration map:

```typescript
import { SUPPORTED_CHAINS } from '@opengrant/sdk';

Object.values(SUPPORTED_CHAINS).forEach(chain => {
  console.log(`${chain.name} (${chain.chainId}) - ${chain.testnet ? 'testnet' : 'mainnet'}`);
});
```

## x402 V2 Protocol

OpenGrant uses the x402 V2 protocol with CAIP-2 network identifiers. When the SDK signs a payment, it uses the chain-specific USDC EIP-712 domain:

```typescript
// EIP-712 domain (auto-configured per chain)
{
  name: "USD Coin",
  version: "2",
  chainId: 8453,
  verifyingContract: "0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913"
}
```

The `network` field in x402 headers uses CAIP-2 format (`eip155:<chainId>`), ensuring cross-chain compatibility.
